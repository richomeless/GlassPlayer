# Glass Player

مشغّل فيديو بتصميم زجاجي، مبني على Glass IPTV: نفس الثيم والأنيميشن والإيماءات.

- مكتبة فيديوهات الجوال مع تبويبات للمجلدات والمفضلة
- فتح ملف من الإعدادات، أو من أي تطبيق (مدير الملفات، المعرض)، أو رابط مباشر
- سلايدر تقديم، تقديم/ترجيع 10 ثواني، سرعة التشغيل، ومتابعة من آخر موضع
- PiP، تشغيل صوت فقط بالخلفية، وإشعار تحكم

## الخطوط
ضع ملفات الخطوط في `app/src/main/res/font/` بهذه الأسماء:
`instrumentsans_regular.ttf`، `instrumentsans_bold.ttf`، `tektur_medium.ttf`
(أو انسخها من مستودع GlassIPTV). بدونها التطبيق يستخدم خط النظام.

## البناء
أي push على `main` يبني التطبيق عبر GitHub Actions، والـ APK يطلع في Releases (وسم `latest`) وفي Artifacts.
